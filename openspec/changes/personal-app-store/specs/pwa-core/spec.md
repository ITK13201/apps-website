## Purpose

PWA マニフェストと Service Worker による installability とオフライン対応。ユーザーがアプリをホーム画面に追加し、ネットワーク接続なしで基本閲覧できるようにする。

## ADDED Requirements

### Requirement: PWA インストール対応
アプリは Web App Manifest を提供しなければならない（SHALL）。ブラウザの「ホーム画面に追加」プロンプトが表示可能な状態を満たすこと。

#### Scenario: モバイルブラウザでホーム画面に追加する
- **WHEN** ユーザーがモバイルブラウザでサイトにアクセスし「ホーム画面に追加」を選択する
- **THEN** アプリアイコンと名前でホーム画面に追加され、スタンドアロンモードで起動する

#### Scenario: デスクトップブラウザでインストールする
- **WHEN** ユーザーがデスクトップブラウザのインストールプロンプトを承認する
- **THEN** ネイティブアプリ風にインストールされ、ブラウザ UI なしで起動する

### Requirement: オフラインでの基本閲覧
Service Worker によってキャッシュされたコンテンツを使い、オフライン時でもアプリ一覧および詳細ページを閲覧できなければならない（SHALL）。

#### Scenario: オフラインでアプリ一覧を閲覧する
- **WHEN** ネットワーク接続がない状態でユーザーがアプリ一覧を開く
- **THEN** 最後にキャッシュされたアプリ一覧が表示される

#### Scenario: オフラインで未キャッシュページにアクセスする
- **WHEN** ネットワーク接続がない状態でキャッシュにないページにアクセスする
- **THEN** オフライン用フォールバックページが表示される

### Requirement: レスポンシブ対応
アプリはモバイル（320px 以上）からデスクトップ（1280px 以上）まで適切なレイアウトで表示されなければならない（SHALL）。

#### Scenario: モバイルサイズで表示する
- **WHEN** ビューポート幅が 768px 未満のデバイスでアクセスする
- **THEN** 単列レイアウトで操作しやすいタッチターゲットサイズで表示される

#### Scenario: デスクトップサイズで表示する
- **WHEN** ビューポート幅が 1024px 以上のデバイスでアクセスする
- **THEN** 複数列グリッドレイアウトで表示される
